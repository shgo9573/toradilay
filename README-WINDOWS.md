# בניית תורה דיליה ל-Windows

הבנייה האוטומטית מופעלת לאחר push ל-main או ידנית דרך GitHub Actions → Build ToraDelia for Windows.

הבנייה מייצרת Portable EXE, מתקין Windows ותיקייה פרוסה ב-ZIP.

## הגדרת מסד נתונים

הגרסה הנוכחית משתמשת ב-PostgreSQL. כתובת המסד אינה מקודדת בקובץ ההתקנה. לפני ההפעלה יש ליצור קובץ `app.env` בתיקיית הנתונים של האפליקציה ולהוסיף:

```dotenv
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DATABASE
```

יש להגדיר מסד נתונים שנגיש ממחשב Windows. אין לכלול סיסמת מסד בקוד או בתוך קובץ ההתקנה.

## Google

כאשר לא הוגדר OAuth קבוע, אפשר להתחבר בחלון Google בלי להזין מפתחות OAuth ידנית. Google מחזירה הרשאת גישה לזמן מוגבל, ולכן לאחר תפוגתה יש להתחבר שוב. חיבור OAuth קבוע שהוגדר מראש ממשיך להתחדש אוטומטית.
